## 🚀 Featured Projects

### [01. GitHub Enterprise Onboarding Agent](projects/01-github-onboarding-agent)
An intelligent RAG-powered assistant built with **LangChain** and **Streamlit**. It eliminates developer onboarding friction by providing instant, grounded answers to enterprise-specific tooling questions with 80%+ context precision.

### [02. Feedback Intelligence Loop](projects/02-feedback-loop-agent)
A multi-agent supervisor system built with **LangGraph** and **FastAPI**. It autonomously aggregates user feedback from App Store reviews, NPS, and Sales calls to detect macro-patterns and generate technical PRDs in seconds.

## 🛠️ Global Intelligence Stack

- **Orchestration:** LangGraph, LangChain
- **Models:** OpenAI GPT-4o-mini (Reasoning), text-embedding-3-small (Embeddings)
- **Data Protocols:** Model Context Protocol (MCP)
- **Vector Storage:** ChromaDB
- **Frontend:** React (Vite), TailwindCSS, Streamlit
- **Backend:** FastAPI, Python 3.12

## 🧠 Core Philosophy

I build agents that prioritize **grounding** and **measurability**. Whether it's using the Relevance Grader in the RAG pipeline or RAGAS for quantitative evaluation, the goal is always to move beyond "AI vibes" towards reliable, production-ready intelligence.
