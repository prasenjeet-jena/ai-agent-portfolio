# 📊 Intelligence Dashboard (Frontend)

The high-fidelity React interface for the **Feedback Intelligence Agent**. This dashboard serves as the human-in-the-loop "Command Center" where Product Managers explore AI-synthesized feedback clusters and take action by generating professional PRDs.

## 🖥️ Overview

The dashboard is designed to solve the "Qualitative Data Overload" problem by transforming messy user feedback into a clean, interactive analytical experience. It consumes the strategic intelligence generated by the underlying LangGraph pipeline and provides the interface for triggering document generation via the FastAPI backend.

### Key Features

1.  **Segmented Intelligence (Sidebar):** Slice and dice feedback by source (App Store, NPS, Sales), user segment, platform, sentiment, and geography.
2.  **Risk Radar:** A high-level visualization of emerging churn risks and severe complaints detected by the AI Analyst agent.
3.  **Active Feedback Clusters:** Interactive cards representing AI-detected themes. Each card shows the priority level, issue count, and a strategic summary.
4.  **Evidence Deep-Dive (Modal):** Allows PMs to trace every AI claim back to the raw user quotes, ensuring full transparency and grounding.
5.  **Autonomous PRD Generator (Modal):** A centered pop-over interface that invokes the PRD Agent to draft professional, technical documents based on specific feedback clusters.

## 🏗️ Technical Architecture

### Component Breakdown

| Component | Responsibility |
| :--- | :--- |
| `App.jsx` | Core state management, data fetching from `latest_intelligence.json`, and global layout orchestration. |
| `FilterSidebar.jsx` | Manages the multi-dimensional filter engine (Source, Segment, Platform, etc.). |
| `TrendGrid.jsx` | Dynamically renders cluster cards based on the active filters and AI-detected themes. |
| `ActionPanel.jsx` | **The PRD Generator.** Acentered modal that communicates with the FastAPI `generate-prd` endpoint and renders the resulting Markdown document. |
| `EvidenceModal.jsx` | Lists the raw, enriched feedback items that comprise a specific theme or signal. |
| `RiskRadar.jsx` | Simple, high-impact component for displaying emerging critical risks. |

### Data Flow

1.  **Local Intelligence:** The dashboard fetches `public/latest_intelligence.json`, which is the output from the `supervisor_graph.py` pipeline.
2.  **State Filtering:** The `App.jsx` engine performs client-side filtering on the `raw_feedback_lookup` and cluster data based on user selections in the sidebar.
3.  **API Integration:** The `ActionPanel` sends a POST request to `http://localhost:8000/generate-prd` with the cluster theme and raw evidence items. The resulting AI-generated PRD is then rendered in-situ using `react-markdown`.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 6
- **Styling:** TailwindCSS 4 (Utility-first, responsive design)
- **Icons:** Lucide React (Clean, consistent iconography)
- **Markdown:** `react-markdown` (For technical document rendering)
- **Dashboard Utilities:** `concurrently` (To boot both the UI and the API server simultaneously)

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- Python 3.12 (For the accompanying API server)

### Installation

```bash
cd projects/02-feedback-loop-agent/ui
npm install
```

### Running the App (Standalone)

```bash
npm run dev
```

> [!TIP]
> The `npm run dev` script in this folder is configured to **concurrently** start both the Vite development server AND the FastAPI backend server (`src/api_server.py`). This ensures the "Draft PRD" button works out of the box.

## 🎨 Design Philosophy

- **Vibrant & Professional:** Uses a "Slate & Blue" palette with high-contrast accent colors for sentiment (Emerald for positive, Red for negative).
- **Glassmorphism:** Light backgrounds with subtle borders and shadows to create a premium, layered feel.
- **Action-Oriented:** Every piece of AI analysis is clickable, leading either to the raw evidence or a direct document-writing action.
